# 40 引用核验（verifier）

输入：`out/sources_pro.md`、`out/arguments.md`

产出：`out/citations.md`

逐条核，不许抽样。

每条一行：

```
引用位置 | 规范+条款 | 我方原文 | 官方原文 | 判定 | 处理
```

判定只有四种：

- **准确**——逐字一致（允许标点差异）。
- **有偏差**——给出正确原文，注明差在哪。
- **无法核实**——找不到官方原文，或只有二手转述。
- **失效/已修订**——注明现行版本与修订文号。

必须额外核对这些数字，一个都不许错：

二年追责期限（处罚法 36 条）、听证申请五日（64 条）、复议六十日（复议法）、直接起诉六个月、复议后起诉十五日。

再核本案文书里的**具体数额**：罚款额、没收违法所得额、货值金额、处罚幅度上下限。要求：

- 数额从本案文书（决定书／告知书）**读出来**，逐字复述并注明出处段落；**不许沿用模板、不许沿用上一个案子的数字**。
- 与 `input/` 里的原件 PDF 逐字比对（抽取稿会吞数字，尤其 WPS 子集字体）。不一致时以 PDF 为准，并把差异写进本表。
- 文书里写 `***` 或空白的，核验结论写"原文未载明"，不许自行推算出数来补。

结尾给"必须删除或改写"清单。凡是标为"无法核实"或"失效"的引用，正文一律不许出现。
