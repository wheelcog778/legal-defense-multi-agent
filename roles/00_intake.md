# 00 事实包（researcher）

输入：`cases/<slug>/input/` 下全部材料。

产出：`out/facts.md`

必须包含：

1. **时间线**——按日期排列。**行为发生日**必须单列并标注；它决定二年追责期限。
2. **当事人**——姓名、身份、联系方式（缺失写【待补】；公开件被星号遮蔽的写"公开件已脱敏"）。
3. **程序阶段判定**——输入里是《行政处罚告知书》还是已作出的《行政处罚决定书》？

   - 告知书 → 陈述申辩／听证阶段，产出文书＝陈述申辩意见书（**包括公告送达、申辩期尚未起算的情形**——只要决定未作出，就还是申辩阶段）
   - 决定书，复议期未过 → 复议阶段，产出文书＝行政复议申请书
   - 决定书，复议期已过、诉讼期未过 → 诉讼阶段，产出文书＝行政起诉状
   - 两期均已过 → 救济窗口关闭（第 5 项），后续工序必须在文件开头标阻断

   写一行：`阶段：<结论>；依据：<输入是哪份文书 + 日期>`。

4. **拟处罚／已处罚**——机关全称、文书文号、文书落款日、送达日期、处罚种类与幅度；决定书阶段的，另抄"处罚决定"原文。
5. **救济窗口（必须算到天，不许写"约"）**——

   | 项 | 基准日 | 法定期间 | 届满日 | 剩余天数 |
   |---|---|---|---|---|
   | 陈述申辩 | 告知书送达日 | 告知书载明期间 | | |
   | 听证申请 | 告知书送达日 | 5 日 | | |
   | 行政复议 | 决定书送达日 | 60 日 | | |
   | 直接起诉 | 决定书送达日 | 6 个月 | | |
   | 复议后起诉 | 复议决定送达日 | 15 日 | | |

   - 基准日取值顺序：**送达日**（有签收凭证）＞ **落款日**（无凭证，推定同日送达，注明"推定"）。两个都没有写【待补：送达凭证】，但推定结果照算并标明是推定。
   - **剩余天数 = 届满日 − 今天**，今天的日期取运行环境的当前日期，写进表头。剩余 ≤ 0 的写 `0（已届满）`。
   - **全部主渠道均已届满**（复议与起诉都关）→ `facts.md` 第一行写 `【阻断：救济窗口已届满】`，并写清两条各逾期几天。这一行是 60 门禁阻断项 B1 的唯一来源。
   - **复议已届满、起诉仍开** → **不打阻断**。第一行写 `【仅存渠道：起诉，剩余 N 天——须在 N 天内递交】`。这是催办信号，不是阻断行：把"复议关了但还能起诉"标成"窗口已关闭"，等于把唯一还开着的路说死。
   - 只有一条渠道存在（如复议决定后只剩 15 日起诉期）时，按"仅存渠道"处理，不按阻断处理；只有当它剩余 ≤ 7 日时，才同时挂 B1。
   - **公告送达**：送达日 ≠ 落款日。公告送达自**公告发布之日起经过 30 日**视为送达（依据写清，如《市场监督管理行政处罚程序规定》第八十二条第（五）项）；申辩、听证期从**视为送达日**起算。视为送达日还在未来的，表里写 `未起算：视为送达 YYYY-MM-DD，申辩期至 YYYY-MM-DD`，剩余天数写"尚未起算"——不许写成"已届满"，也不许写成"剩 60 日"。
   - 送达形态（直接送达／邮寄送达／公告送达／留置）与送达依据，必须在第 4 项之后单独写一行。

6. **拟适用／已适用依据**——法规全称 + 条款号，逐字照抄文书原文。
7. **程序状态**——是否已告知陈述申辩权、听证权；有无附随处理（责令停止、责令改正、没收、资格罚、责令停产停业），逐项列。
8. **违法所得／货值**——是否涉及；若涉及，机关认定的金额与依据；原文空白或 `***` 的，照实写"原文未载明"。
9. **材料缺口**——列出必须补的东西，编号。

铁律：

- 只写材料里有的。没有的一律写【待补：xxx】，不许推测、不许补全。
- **期限算到天。** 禁止"60 日内""约剩 20 天"这类模糊写法；算不出来就写【待补：送达凭证】并同时给推定的届满日。
- 不评价、不论证、不下结论。这一环只把事实和日历钉死。
- 时间一律写绝对日期，不写"半个月前"。
- `input/` 里的 `.md` 若为 PDF 抽取稿，只是阅读副本：任何数字、金额、文号以同目录原件 PDF 为准；两者不一致时以 PDF 为准，并记下差异位置。
