# 20 抗辩路径构建（analyst）

输入：`out/sources_pro.md`、`out/sources_con.md`、`out/case_law.md`、`out/conflicts.md`、`out/concepts.md`
产出：`out/arguments.md`

## 排序原则

**按实际可突破性排，不按理论漂亮程度排。**

一个论证在法律上再漂亮，如果同类案件里法院从没采纳过，就不该排第一。排序依据：类案采纳频次 > 规范强度 > 论证美感。

## 每条一节的格式

```
主张（一句话，能直接写进申辩请求）：
法源：（条款 + 原文）
类案支持：（案号 + 结果；没有就写"无类案支持"）
冲突与概念依据：（引 conflicts.md / concepts.md 的哪一条）
推理链：（三段以内）
对方最强反驳：（来自 sources_con 与 case_law 的维持案例）
再回应：
预期采纳率：高 / 中 / 低，依据是____
```

## 必须有的两层

1. **主张层**：至少三条，按可突破性排序。
2. **退一步层**：主张不成立时落到——情节轻微（33 条 1 款）、无主观过错（33 条 2 款）、超过二年追责期限（36 条）、从旧兼从轻（37 条）、程序瑕疵（44、45、63 条）。

## 数值类要件的第一问

货值、违法所得、销售金额、纳税额——这些数在材料里算不出来时，**先问它是不是处罚成立的要件**，再决定怎么打。

- 罚则是**定额幅**（如"一百万元以下"，不含下限；或"五千元以上五万元以下"但本档不依赖货值）→ 货值不是本证要件，"算不出"只能影响裁量档次，写成"竞合未评价、裁量无档次说理"，不要拿"无法计算"当主攻点。
- 罚则是**以货值／违法所得为函数**（如"货值金额 X 倍"、"违法所得一倍以上十倍以下"）→ 数值缺失直接打掉本证，主攻点就是"计算基础不成立"。

把两者混着写，等于自弃一个真论据、还把另一个说成程序瑕疵。

## 必须有一条程序性突破口

如果存在：时效、管辖、告知瑕疵、听证未告知、证据来源违法。程序问题在实务里的撤销率通常高于实体解释之争，别把全部篇幅压在法条解释上。

## 禁止

情绪化、"显然"、"众所周知"、无原文支撑的推断、对机关的道德评价、拿孤例当趋势。
