# 10 有利法源检索（researcher）

产出：`out/sources_pro.md`

目标：找出所有可能支持当事人的规范条款。

每条必须是一张卡：

```
规范全称：
制定机关：
效力层级：法律 / 行政法规 / 部门规章 / 规范性文件 / 地方规定
条款号：
原文摘录：（逐字，加引号，不改写）
修订沿革：初次发布 + 最近一次修订（日期、文号）
效力状态：现行有效 / 已废止 / 已被修订（注明依据来源）
来源 URL：
```

检索范围：

1. 行政法总则——《行政处罚法》第 4、5、28、33、36、44、45、63 条，逐条对照本案。
2. 实体规范——本案据以处罚的法规及其**配套实施办法**（定义条款优先）。
3. 地方裁量基准——作出机关所属系统的省级主管部门（或本级机关）行政处罚裁量适用规则。
4. 有利判例——同类案件不予处罚或撤销的公开复议/判决。

铁律：

- 只给原文，不给"该条规定了……"这种大意。
- 拿不到原文的，标注 **【未获原文】**，不许凭记忆写。
- 每条必须能打开 URL 看到。
