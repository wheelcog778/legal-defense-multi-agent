# 50 文书成稿（writer）

输入：`out/arguments.md`、`out/redteam.md`、`out/citations.md`

产出：按 `facts.md` 判定的程序阶段选文书形态：

| 阶段 | 产出文件 |
|---|---|
| 陈述申辩／听证（收到告知书） | `out/陈述申辩意见书.md` |
| 复议（决定书已作出、复议期未过） | `out/行政复议申请书.md` |
| 诉讼（复议期已过、诉讼期未过） | `out/行政起诉状.md`（含请求撤销／确认违法） |
| 两期均已过 | 不出文书，只出 `out/救济窗口说明.md`：哪条已关、有没有其他途径（申诉、检察监督、信访）、为什么不能再递 |

判错阶段＝整份文书白写：向法院递一份"陈述申辩意见书"，等于自己放弃诉权。

结构固定（以申辩意见书为例，复议／起诉状同构，标题与请求项按阶段换）：

```
标题
致：（机关全称）
申辩人信息
案由（告知书文号、送达日期、拟处罚内容、拟适用条款原文）
申辩请求（分项，可执行）
事实与理由（逐节，标题即论点）
此致
落款
附录一 法律依据对照表
附录二 证据清单
附录三 程序权利与救济途径
```

铁律：

1. 只用 `citations.md` 判为**准确**的引用。判为"无法核实"的，删。
2. `redteam.md` 列出的自认句，全部改成假设性表述（"即使假定……"）。
3. 补上 `sources_con.md` 里"我方不能回应"的缺口，用退一步层兜住。
4. 不写"我认为""显然""严重违法"这类主观词。事实用陈述句，法律用"依据……之规定"。
5. 文末保留一句：本材料系依据现行有效规范整理，不构成正式法律意见，重大案件建议由执业律师复核。
