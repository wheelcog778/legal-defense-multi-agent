# 60 提交前检查（verifier）

输入：成稿（陈述申辩意见书／行政复议申请书／行政起诉状），或 `out/救济窗口说明.md`；`checklist.md`；`out/facts.md`

产出：`out/gate.md`

## 第一步：按产出类型选表

看 `facts.md` 的程序阶段判定：

| 产出 | 用哪张表 |
|---|---|
| 文书类（申辩意见书／复议申请书／起诉状） | checklist **表 A**（26 项） |
| 救济窗口说明（两期均已过） | checklist **表 B**（M1–M12） |

选错表，整张门禁作废——拿 A 表去检窗口说明，#4 全文通读、#22 附件对应会全 fail，结论被一堆与产物无关的 fail 污染。

表 B 还有一个盲区要堵：走窗口说明这条出口时，12 岗（类案）与 40 岗（引用核验）没有对应的 A 表项可打勾，容易被静默跳过。M12 就是为此设的——说明里只要引了任何法条或类案，就必须给出 40 岗结论或明示"未核"，12 岗的状态必须写进去。

## 第二步：逐项判定

只有四种结果：

- **pass** ——符合。
- **fail** ——不符合且**改得动**，必须写清改哪一句、改成什么。不允许写"建议注意"。
- **n/a** ——只限两种：该项依赖的材料本包没有；公开件已被遮蔽。必须写理由。
- **blocked** ——该项依赖外部原文／检索通道，而通道确实不可用。不计 pass 也不计 fail，但必须出现在结论行。依赖外部通道的项（A#4、#6、#9、#11、#12、#13、#15）通道不可用时**统一判 blocked**，不许一个判 n/a、一个判 fail。

## 第三步：期限项的分寸（A#21）

- 规则没核 → fail。
- 只核规则、没算日历（届满日与剩余天数）→ fail。
- **算出来已届满（剩余 ≤ 0）→ 判 pass**，理由里写届满日与逾期天数，后果交给阻断项 B1。已届满不是错误，改任何句子都改不动它；判 fail 会造出一条"无回改空间"的 fail，破坏"fail＝可改"的契约。

## 第四步：阻断项

两张表之外**只允许**一个阻断项：

- **B1：救济窗口已届满或剩余 ≤ 7 日**（数据来自 `facts.md` 的窗口表）。写在表后、结论行前，不计入表内统计，但必须进结论行。

## 第四步半：统计行（必写，别让人自己数）

结论行之前必须先给一行合计，四个数相加必须等于所查表的项数（表 A 26 / 表 B 12）：

```
统计：pass <a> / fail <b> / n/a <c> / blocked <d>，合计 <a+b+c+d> = <表项数>
```

对不上＝漏项或多判，本卡判未完成。

## 第五步：结论行（格式写死）

```
结论：可提交（fail 0，阻断 0，blocked 0）
结论：不可提交（fail <n>，阻断 <B1 或 0>，blocked <k>）
blocked 明细：<k> 项（#4 #6 #9 #11 #12 #13 #15 中实际生效的那几项）
```

- **blocked 必须列明细**，且分两类写：`环境性`（无网、无 key、包内缺原件——换环境可补）与 `实质性`（该核而材料本身没有——必须做）。不分类的 blocked 会让结论行永远一样长，看不出到底缺什么。

- **fail 0 但 blocked > 0，仍是"不可提交"**：未核＝未证。
- 结论行只许有结论。同一行及其后紧接的一段不许出现"可先作为初稿递交""补齐后可提交""同步申请调卷"之类表述。
- 出现"基本可提交""建议修改后提交""不宜提交但…"，本卡判为未按契约执行，退回重做。
- 回改清单另起一节，逐条对应 fail 项。

不许因为"时间紧"放行。放行一次，前面十道工序全部作废。
