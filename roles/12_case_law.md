# 12 类案与裁判倾向（analyst）

输入：`out/facts.md`
产出：`out/case_law.md`

## 目的

回答一个问题：**这类案子，现实里是怎么判的？**

理论强度不等于实际可突破性。法院和复议机关实际撤销的理由，集中在几类：程序违法、事实不清、适用法律错误、明显不当、超越职权。你要知道这一类里哪一扇门是开着的。

## 检索通道不可用时（先判这一条）

动手检索前，先确认通道：网络检索、裁判文书库、法规库能否取到正文。取不到就**不要**用"未见类案""样本数 0"收尾——那会让门禁误判成"本岗已执行、只是没有类案"。

此时本岗输出只有一句话开头，然后停止：

```
本岗不可执行（检索通道不可用：<具体原因，如 web_search 无 API key / 文书网正文需登录 / 全部请求超时>）
已尝试：<检索词 × 次数、目标站点、失败特征>
替代方案：<由当事人提供同类判决案号；或改用纸质/线下检索；或明确在成稿中标注"未做类案排序">
```

门禁 #11 对这种状态判 **blocked**，不计 pass、不计 fail。但如果检索通道正常、只是没找到类案，必须给样本数与检索式，按正常口径判 pass。

## 检索对象

1. 行政复议决定书（本级政府、上级主管部门公开的）
2. 行政判决书（同类争点，一审、二审）
3. 上级机关发布的典型案例、执法指引
4. 同类案件的不予处罚决定

## 每条输出

```
案号 / 决定书文号：
机关 / 法院：
年份：
事实类型：（与本案的可比点、不可比点）
争点：
结果：维持 / 撤销 / 变更 / 确认违法 / 不予处罚
裁判理由：（原文摘录）
援引条款：
```

## 统计与结论

1. **撤销理由分布**：程序违法 / 事实不清 / 适用法律错误 / 明显不当 / 超越职权，各占多少。
2. **本案最可能被采纳的突破口**：按"同类案件实际被采纳的频次"排序，不按理论漂亮程度排序。
3. **反面证据**：有没有同类案件被维持的？维持的理由是什么？必须列，不许只挑有利的。

## 铁律

- 区分"个案"和"主流"。一个孤例不能当趋势，必须给样本数。
- 案号/文号必须可查。查不到的标注【未能核实】。
- 没有类案支持的争点，在第 6 步里必须显式标注"无类案支持"，不许含糊。
