# 行政处罚申辩：十道工序 + 一道门禁

一份可以转给任何人的操作手册。不需要是律师，不需要会写代码，用任何 AI 都能跑。

---

## 先说清楚这东西解决什么

大多数人写申辩，是把自己的委屈讲一遍。机关看两页就归档。

有效的申辩不是讲道理，是**堵路**：把对方能用的依据一条条找出来，逐条封死，最后留一条退路给自己。

这套流程把这件事拆成十个岗位。每个岗位只干一件事，任何 AI 都能扮演。你只负责按顺序走，不要跳。

## 为什么是十道，不是三步

因为真实案件里让人赢的，往往不是"找到一个有利法条"，而是下面三件事：

- **知道这类案子现实里怎么判**——法院实际撤销的理由集中在哪里。
- **知道哪一条说了算**——同一个词在两部规范里可能是两个意思。
- **知道这个词以前是什么意思**——法条改了，定义跟着变，用错版本等于用错法。

## 开始前，先凑齐材料

| 材料 | 为什么必须有 |
|---|---|
| 行政处罚告知书（或处罚决定书） | 上面写着机关拟用的条款，逐字抄下来 |
| 询问笔录 / 检查记录 | 机关认定的事实以它为准 |
| 你自己的陈述 | 时间、地点、经过，越具体越好 |
| **行为发生日** | 最关键的一个日期，决定还能不能被罚、适用哪个版本 |
| 送达日期 | 决定申辩、听证的期限 |

材料不齐就往下走，出来的东西全是空的。宁可先补材料。

## 怎么用

每一步，把那一节的**提示词**整段复制，附上它要的材料，发给 AI。它给出结果后，存成一个文件，再进下一步。

十步做完，你会得到一份可以直接递的文书。中间不要跳步——跳一步，后面的全部作废。

---

## 第 0 步 · 事实包

只钉事实，不论证。

```
你是本案的事实记录员，不是律师。只做一件事：把材料里有的事实和日历钉死。

材料：
【粘贴告知书/决定书、笔录、你的陈述、送达凭证】

要求：
1. 输出时间线，按日期排列；"行为发生日"单列并加粗。
2. 列出当事人信息、执法机关全称、文书文号、落款日、送达日期、处罚（或拟处罚）种类与幅度。
3. 逐字抄录文书里"依据"那一段的原文，不改一个字。
4. 判定程序阶段：收到的是告知书（→申辩），还是已作出的决定书（→复议／诉讼）？两期都过了吗？写一行"阶段：……；依据：……"。
5. 算救济窗口，必须算到天：复议 60 日、起诉 6 个月、复议后 15 日、听证申请 5 日。基准日优先用送达日，没有送达凭证就用落款日并注明"推定"。剩几天写几天，过期的写"0（已届满）"。
6. 送达形态写一行：直接送达／邮寄／公告／留置，依据哪一条。公告送达的，送达日＝公告发布日 + 30 日（视为送达），申辩期从视为送达日起算；视为送达日还没到的，写"未起算：视为送达 X 日，申辩期至 Y 日"。
7. 列出"材料缺口"，编号，写清缺什么。

铁律：材料里没有的，写【待补：xxx】。不许推测，不许补充常识，不许下结论。
期限不许写"60 日内""大约还有 20 天"，必须给届满日和剩余天数。
任一主渠道已届满，第一行写【阻断：救济窗口已届满】。
```

## 第 1 步 · 有利法源

```
你是当事人的法源检索员。目标：找出所有可能支持当事人的规范条款。

案件：
【粘贴第 0 步的事实包】

每条按这个格式输出：
规范全称 / 制定机关 / 效力层级 / 条款号 / 原文逐字摘录 / 修订沿革（初次发布 + 最近一次修订的日期与文号）/ 效力状态 / 来源网址

检索范围：
1. 《行政处罚法》第 4、5、28、33、36、37、44、45、63 条，逐条对照本案。
2. 本案据以处罚的法规，以及它的配套实施办法（定义条款优先看）。
3. 省级主管部门（或本级机关）的行政处罚裁量基准。
4. 同类案件不予处罚或撤销的公开案例。

铁律：只给原文，不给"该条规定了……"这种大意。拿不到原文的标【未获原文】，不许凭记忆写。
```

## 第 2 步 · 不利法源（最容易跳过的一步）

**你现在不是当事人的代理人，是对方的法律顾问。**

```
你是行政机关的法制科，不是当事人的代理人。任务是替对方找依据。

案件：
【粘贴第 0 步的事实包】

必须做四件事：
1. 把据以处罚的法规和它的配套实施办法逐条读完，列出所有与本案行为沾边的条款——尤其是罚则条款，以及对"个人"直接处罚的条款。
   （典型漏项：只读了被援引的那一条，漏掉配套办法里对个人的罚则。）
2. 列出邻近规范：其他部委规章、行政规范性文件、地方性法规、地方主管部门执法指引。
3. 找公开的同类处罚决定书，看该机关实际援引哪一条、怎么写事实、怎么驳申辩。
4. 回答"换条不换事"：如果不按告知书那条办，还能按哪一条办？

每条输出：条款 / 原文 / 对方会怎么用 / 我方现有论证能否回应（能 / 不能 / 部分）/ 若不能，缺口是什么

**输出第一行必须点名漏项**（强制）：
"漏项点名：〈前一稿或机关文书〉未援引〈规范+条款〉，它可以这样用：……，我方现有论证回应不了。"
没有前一稿，就点机关文书里没引、但对方能换用的那一条。一条都点不出来 = 这一步没干成，别往下走。只列法条不点名，等于把对抗性降级成普通检索。

铁律：漏一条等于全文白写。宁可多列十条用不上，不许漏一条能要命的。
```

## 第 3 步 · 类案与裁判倾向

理论强度不等于实际可突破性。

```
你是类案检索员。任务：找出这类案子现实里是怎么判的。

案件：
【粘贴第 0 步的事实包】

检索：行政复议决定书、行政判决书、上级机关典型案例、同类不予处罚决定。

每条记录：案号或文号 / 机关或法院 / 年份 / 与本案的可比点与不可比点 / 争点 / 结果（维持 / 撤销 / 变更 / 确认违法 / 不予处罚）/ 裁判理由原文 / 援引条款。

然后统计：撤销理由分布（程序违法、事实不清、适用法律错误、明显不当、超越职权）各占多少。

最后回答两问：
1. 本案最可能被采纳的突破口是哪一类？按同类案件实际被采纳的频次排，不按理论漂亮程度排。
2. 有没有同类案件被维持？维持的理由是什么？必须列，不许只挑有利的。

铁律：一个孤例不能当趋势，必须给样本数；查不到的案号标【未能核实】。

如果检索通道不可用（网络抓不到、文书网要登录、全部超时），不许用"未见类案"收尾。改写成一句：
"本岗不可执行（检索通道不可用：〈具体原因〉）"+ 已尝试的检索式与失败特征 + 替代方案。
门禁第 11 项对此判 blocked，不给 pass——否则门禁分不清"确实没类案"和"这一岗根本没跑"。
```

## 第 4 步 · 规范冲突与定义审查

这一步回答的不是「有哪些条款」，是**「哪一条说了算」**。

```
你是规范冲突审查员。任务：在构建抗辩之前，确定哪一条规范说了算。

有利法源：
【粘贴第 1 步】

不利法源：
【粘贴第 2 步】

按四类逐类过：

A 定义冲突：同一个概念在不同规范里的定义原文，逐条对照，给出差异、应适用哪个、理由。
  高发概念：违法所得、货值金额、较大数额、情节严重、初次违法、拒不改正、经营者／销售者、广告／商业宣传。

B 效力冲突：上位法 > 下位法；法律 > 行政法规 > 部门规章 > 规范性文件。
  必须回答：拟处罚依据属于哪一层？我用来解释它的文件在哪一层？据以处罚的规范有没有创设上位法没有的处罚？

C 新旧冲突：规范修订后，配套办法的依据是否还匹配？未被明文废止，等不等于继续有效（不等于，要给仍被援引的证据）。

D 竞合冲突：同一行为被多条罚则覆盖时，列对比表：
  条款 / 要件 / 处罚幅度 / 是否须先警告 / 能否直接罚个人 / 追责期限

冲突解决规则，按顺序用：
上位法优先 → 特别法优先 → 新法优先 → 文义优先不得类推 → 存疑有利于相对人
每用一条，写明用在哪一处、为什么。

输出：
1. 四类冲突表（带原文和条款号）
2. 结论：主攻哪一条、为什么它能赢；哪几条不能当主攻点
3. 必须回填到抗辩构建的修正

铁律：拿不准的标【存疑：需律师确认】，不许硬下结论。
```

## 第 5 步 · 法条沿革与不确定概念

同一个词，二十年前和现在可能不是一个意思。有些词，本身就没有确定边界。这两件事都是空间。

```
你是法条沿革与概念审查员。

有利法源 / 不利法源：
【粘贴第 1、2 步】

A 概念沿革：对本案每个核心概念做版本对照
  概念 / 旧法版本与原文 / 新法版本与原文 / 变化类型 / 对本案的意义
  变化类型只能填：未变 / 表述微调 / 外延扩大 / 外延缩小 / 概念替换 / 删除
  必须回答：行为发生时适用哪个版本？
  （行政处罚法第 37 条：适用违法行为发生时的规定；作出决定时规定已修改且处罚较轻的，适用新规定。）

B 不确定概念：外延不清、必须解释才能适用的词
  每个列出：概念 / 出自哪条 / 可能的解释（至少两种）/ 支持依据 / 对我方有利还是不利 / 说明责任在谁
  高发词：情节严重、情节轻微、较大数额、违法所得、货值金额、危害后果、及时改正、初次违法、擅自、拒不改正、社会危害性

C 可争点清单：争点 / 打开方式 / 依赖哪条原文 / 预期效果 / 风险

三个可用方向：
1. 明确性原则——依据越模糊，越不能作不利于相对人的扩张解释。
2. 判断余地不等于免审——机关对不确定概念有判断空间，但法院仍审查是否超出文义、是否违反比例原则。
3. 裁量基准——有没有公开？有没有适用？同类案件处理是否一致？不一致可主张裁量滥用。

铁律：旧法必须写年份和文号；不许只挑有利解释，对方的解释也要写。
```

## 第 6 步 · 抗辩构建

```
你是当事人的代理人。基于下面五份材料构建抗辩路径。

有利法源 / 不利法源 / 类案 / 冲突结论 / 概念清单：
【粘贴第 1 至 5 步】

排序原则：按实际可突破性排，不按理论漂亮程度排。
类案采纳频次 > 规范强度 > 论证美感。

每条输出：
主张 / 法源（带原文）/ 类案支持（案号+结果，没有就写"无类案支持"）/ 冲突与概念依据 / 推理链 / 对方最强反驳 / 再回应 / 预期采纳率（高 / 中 / 低）及依据

两层必须都有：
1. 主张层：至少三条，按可突破性排序。
2. 退一步层：情节轻微（33 条 1 款）、无主观过错（33 条 2 款）、超过二年（36 条）、从旧兼从轻（37 条）、程序瑕疵（44、45、63 条）。

另外单列"程序性突破口"（如果有）：时效、管辖、告知、听证、证据来源。
程序问题在实务里的撤销率通常高于实体解释之争，别把全部篇幅压在法条解释上。

禁止：情绪化、"显然"、"众所周知"、无原文支撑的推断、拿孤例当趋势。
```

## 第 7 步 · 红队

```
你是作出处罚的机关的法制审核人，目标是驳回这份申辩。

申辩路径 / 不利法源 / 类案 / 概念清单：
【粘贴第 2、3、5、6 步】

逐条攻击，四种打法：文义 / 体系 / 目的 / 类案（引维持案例的案号）。

必须回答四问：
1. 换条不换事：我不接受你的解释，改用另一条，你怎么办？
2. 概念替换：你依赖的那个不确定概念，我给出另一种同样成立的解释，你还剩什么？
3. 程序反击：时效、管辖、告知瑕疵、证据来源，逐项给结论。
4. 自认风险：材料里哪些句子构成不利的事实承认？逐句摘出，给替代表述。

结尾一句话：这份申辩明天递上去，最可能死在哪一句。
```

## 第 8 步 · 引用核验

法条引错一个字，整份材料的可信度就没了。

```
你是引文核对员。逐条核对，不许抽样。

待核引用：
【粘贴第 1、4、5、6 步里的全部引用】

每条输出：规范 + 条款 / 我方原文 / 官方原文 / 判定 / 处理

判定只有四种：
准确 / 有偏差（给出正确原文）/ 无法核实（找不到官方原文）/ 失效或已修订（注明现行版本与修订文号）

另外核对这五个数字，一个都不许错：
二年追责期限、听证申请五日、复议六十日、直接起诉六个月、复议后起诉十五日。

结尾给"必须删除或改写"清单。
```

## 第 9 步 · 成稿

```
你是文书撰写人。只能用核验通过的引用。

材料：抗辩路径 / 红队意见 / 核验结果：【粘贴第 6、7、8 步】

结构：
标题 / 致（机关全称）/ 申辩人信息 / 案由 / 申辩请求（分项）/ 事实与理由（每节标题就是论点）/ 此致 / 落款 / 附录（法条对照表、证据清单、程序权利指引）

铁律：
1. 只用判为"准确"的引用，其余全删。
2. 红队指出的自认句，全部改成假设性表述（"即使假定……"）。
3. 不写"我认为""显然""严重违法"。
4. 文末保留：本材料依据现行有效规范整理，不构成正式法律意见，重大案件建议由执业律师复核。
```

## 第 10 步 · 门禁

最后一道。过不了就别递。

```
你是提交前的最后检查人。先选表，再逐项判定。

产出是哪一种，先定：
· 文书（申辩意见书／复议申请书／起诉状）→ 用表 A
· 救济窗口说明（复议、起诉两期都已过，不出文书）→ 用表 B

判定只能填四种：
pass ＝ 符合
fail ＝ 不符合，且改得动（必须写清改哪一句、改成什么）
n/a ＝ 只限两种：该项要的材料本包没有；公开件已被打星号遮蔽（必须写理由）
blocked ＝ 该项要靠外部原文或检索通道，而通道确实不可用（不计 pass，也不计 fail，但必须出现在结论行）
靠外部通道的项（A 的 4、6、9、11、12、13、15）通道不可用时，一律判 blocked——不许有的判 n/a、有的判 fail。

【表 A · 文书类 26 项】
| # | 检查项 | 判定标准 |
|---|---|---|
| 1 | 行为发生日已确定 | 有绝对日期；原文只写"某次检查时"的，写"不晚于 X"并标注推定依据，判 pass；持续型违法（如"连续2年未报送"）按义务终了日下限推定、写明链条，也判 pass；无日期也无推定＝fail；另给是否满二年结论 |
| 2 | 二年追责期限已主张或已排除 | 超过则单列为一节，未超过则在材料中说明 |
| 3 | 拟处罚依据与告知书一致 | 有告知书+有决定书→两份逐字核对并单列"依据有无变更"；告知阶段（决定未作出）→ 判"告知内容与拟适用依据逐字自洽"，注明比对对象是告知书本身；无告知书→ n/a |
| 4 | 同一部规范已全文通读 | 列出全部相关条款，含罚则与对个人处罚条款 |
| 5 | 换条不换事已评估 | 每一可能替代条款都有应对 |
| 6 | 定义冲突已列全 | 同一概念在不同规范中的定义原文与差异已对照 |
| 7 | 效力层级已核 | 上位法/特别法/新法规则写明用在哪一处、为什么 |
| 8 | 竞合条款已比较 | 罚则要件与幅度列过表，主攻点不依赖会被推翻的条款 |
| 9 | 概念沿革已做版本对照 | 旧法/新法原文并列，变化类型与适用版本已写明 |
| 10 | 不确定概念已列出 | 每个概念给至少两种解释，写明有利与不利、说明责任 |
| 11 | 类案支持已标注 | 每条主张有案号或明确写「无类案支持」；检索通道不可用判 blocked |
| 12 | 每条引用有官方原文 | 无原文的引用已删除 |
| 13 | 引用效力状态已核 | 现行有效 / 已修订，注明文号与日期 |
| 14 | 修订沿革已核 | 不出现"2024 年修订"这类无法核实的表述 |
```

## 三条铁律

**一、引用必须是原文。** 大意、转述、「根据有关规定」——这些都等于没有。

**二、不利检索先于构建。** 先知道对方能怎么打，再决定说什么。反过来做，材料一定漏。

**三、先看现实怎么判，再谈理论多漂亮。** 没人采纳过的漂亮论证，排在能被采纳的朴素论证后面。

**四、门禁不过不提交。** 有一个 fail 就回去改。放行一次，前面九步全部作废。

## 八种最常见的死法

1. 只读了被援引的那一条，没读配套办法里的罚则 → 对方换个依据，全篇作废。
2. 没算二年追责期限 → 明明已经过期，还在长篇论证。
3. 违法所得定义自己编 → 应该直接引法条原文。
4. 通篇承认了行为事实 → 后面所有的法律解释都建立在承认之上。
5. 引用了一部已废止或已修订的规范 → 一句话被推翻。
6. 只写请求，不写被驳回后的退路 → 一旦驳回，什么都没有。
7. 没查定义冲突，主攻点建在一条会被上位法或新法推翻的条款上 → 三千字，一句话作废。
8. 拿旧法时期的解释套新法，或者只挑对自己有利的那种解释 → 对方一句"该概念已修改"就结束。
